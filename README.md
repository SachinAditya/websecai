# WebSecAI

## AI-Powered Web Security Assistant

WebSecAI is an AI-powered web security assistant designed to help developers,
students, and authorized security testers understand web security findings.

It combines deterministic, non-destructive security checks with an
open-weight AI model such as Gemma to explain findings, assess severity,
and provide practical remediation guidance.

> ⚠️ WebSecAI is intended for authorized security testing and defensive
> security analysis only. Do not use it against systems without permission.

---

## 🚀 Features

- Security header analysis
- Cookie security analysis
- CORS configuration analysis
- HTTPS/security configuration checks
- Security finding classification
- Severity assessment
- AI-powered security explanations
- AI-generated remediation recommendations
- Security score/dashboard
- Security report generation
- HTTP request/response evidence analysis
